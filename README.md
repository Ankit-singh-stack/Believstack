# Believstack

Believstack is a modern fullstack development startup. We provide end-to-end web and app development services, specializing in the MERN stack (MongoDB, Express, React, Node.js).

## Features
- Home, About Us, Services, Projects, Contact Us pages
- Modern, clean, and professional design
- Responsive and user-friendly UI
- Backend API with Express and MongoDB

## Getting Started

### Prerequisites
- Node.js
- npm
- MongoDB

### Setup

#### Backend
```
cd server
npm install
npm start
```

#### Frontend
```
cd client
npm install
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) for the frontend and [http://localhost:5000](http://localhost:5000) for the backend API.
